# 진행 기록

## 11/10 (화) 14~15시 — 데이터 수집 1차

- 작업: 빨간 블록 3개(대·중·소)를 파란 트레이 위에 큰 것 → 중간 → 작은 것 순서로 쌓기
- 블록과 트레이 시작 위치를 보드에 펜으로 표시해 조건 통일
- 카메라: Logitech C922 1대, 640×480, 30 fps, 작업대 정면 시점
- 에피소드 최대 30초, 작업을 마치면 완료 버튼으로 종료
- 목표 50회 중 약 30회 녹화
- 역할 분담: 시연(1명), 녹화 조작, 블록 리셋, 촬영, 자세·배치 점검

## 11/11 (수) 12~13시 — 데이터 수집 2차

- 나머지 약 20회 녹화. 조작에 익숙해져 첫날보다 빨리 끝남
- 실패 시도(블록 놓침, 탑 무너짐)는 reset으로 중단해 저장하지 않음
- 결과: 약 50회 시연 중 25개 에피소드 저장 (21,102프레임)

## 11/16 (월) — 학습

- ACT, LeRobot 0.2.0 기본 하이퍼파라미터 (batch 8, lr 1e-5, KL weight 10)
- chunk_size / n_action_steps = 100 / 100, temporal ensembling 꺼짐, 영상 증강 꺼짐
- 영상이 손상된 11·18번을 빼고 23개 에피소드(19,300프레임) 사용
- RTX 3080 1장, 15:25 ~ 16:07 (약 42분)
- 30,000 step 설정, 29,000 step 직후 수동 종료 → 마지막 저장본인 25,000 step 사용
- 학습 loss: 약 3.4 → 약 0.10

## 11/18 (수) 12~13시 — 추론 실험

- 25,000 step 모델로 실행, 지시문 "stack the big blocks first.", 30 FPS
- 기본 조건 여러 차례 시도 → 모두 실패
- 변형 조건 3가지 → 모두 실패
  - ① 그리퍼에 블록을 손으로 넣어 줌
  - ② 큰 블록을 미리 트레이에 옮겨 둠
  - ③ 블록 2개를 미리 쌓아 둠
- 공통 패턴: 대략적인 경로는 따라가지만 블록 위에서 정밀하게 잡거나 놓지 못하고, 블록을 밀거나 쓰러뜨린 뒤 맴돌다 멈춤
- 체크포인트에서 이어 학습할 수 없어, 재학습 없이 결과 분석으로 진행

## 11/19 ~ 11/23 — 분석 및 보고서

- 설정 파일, 모델 파일, 데이터셋 메타데이터, 학습 로그, 실행 영상 대조
- 모델 파일 분석: 전체 파라미터 51,668,656개 (추론 시 약 3,420만 개)
- 실행 영상 3개에서 장면 캡처 정리
- 실패 원인을 데이터 양·일관성, 긴 action chunk, 카메라 1대, 학습 step, 조명 조건으로 분석
